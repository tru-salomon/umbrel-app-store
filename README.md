# Tru's Umbrel App Store

Personal community app store for umbrelOS.

## Apps

- **Paperclip (patched)**: Paperclip 2026.1106.0 with server-side renewal of
  Claude subscription OAuth tokens (upstream PR #15319), so Claude subscription
  connections keep working past the 8-hour token expiry.

## Install

In umbrelOS, open App Store → ⋯ → Community App Stores, add
https://github.com/tru-salomon/umbrel-app-store, then install from the store.

This is a personal build. It is not affiliated with Paperclip Labs or Umbrel.
